# Data dictionary (synthetic)

Generated by `server/synth.py` with seed 20261023. Every row describes a fictional company.
CSV exports are written by `python3 scripts/generate_data.py`.

## resources (inventory)
| Column | Type | Meaning |
|---|---|---|
| resource_id | text | `vm-NNNN` |
| name | text | Synthetic VM name, for example `prod-checkout-api-01` |
| resource_type | text | Catalogue size, for example `gp-4x16` |
| family | text | general, compute or memory |
| vcpu, ram_gb | int | Configuration from the catalogue |
| region | text | Mumbai, Hyderabad or Singapore (simulated) |
| environment | text | Production, Staging or Development |
| team | text | Engineering, Data, Platform, Analytics or QA |
| state | text | Always `running` at generation time |
| created_at | text | ISO timestamp, IST |
| hourly_inr | real | Synthetic hourly price |
| criticality | text | Critical, High, Medium or Low |
| schedule_allowed | int | 1 if the owner allows off-hours scheduling |
| restriction_note | text | Operational constraint, for example a nightly batch window |
| public_ip | int | 1 if the VM has an attached public IP |
| scenario_note | text | Demo label explaining why the VM is in the named scenario. Not used by the analysis |

## volumes
| Column | Meaning |
|---|---|
| volume_id | `vol-NNNN` attached to a VM, or `vol-orphan-NNNN` |
| resource_id | Attached VM, or empty for orphans |
| size_gb | Capacity |
| volume_type | block-ssd |
| created_at, detached_at | ISO timestamps. detached_at is set only for orphans |

## public_ips
| Column | Meaning |
|---|---|
| ip_id | `ip-NNNN` or `ip-orphan-NNNN` |
| address | Address from documentation ranges (203.0.113.x, 198.51.100.x). Not real |
| resource_id | Attached VM, or empty |
| allocated_at, detached_at | ISO timestamps |

## metrics (15-minute measurements)
| Column | Unit | Meaning |
|---|---|---|
| resource_id | | VM identifier |
| ts | epoch seconds (UTC) | Measurement time |
| cpu_pct, mem_pct, disk_pct | % (0–100) | Utilization |
| disk_iops | operations/s | Storage activity |
| net_in_mbps, net_out_mbps | Mbps | Network throughput. Egress GB = Mbps x 900 / 8 / 1024 per interval |

Deliberate quality issues in `staging-web-01`: 3 invalid values and 2 duplicate rows.
`dev-qa-regression-01` has 40% of its intervals removed.

Export with `python3 scripts/generate_data.py --with-metrics` or use `/api/export/metrics.csv`.
